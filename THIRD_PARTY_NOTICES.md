## FFmpeg (opsis-ffmpeg)

Opsis ships FFmpeg as a separate program, `opsis-ffmpeg`, installed beside the app's own program, and starts it for every encode, mix and decode. It is the unchanged GPLv3 build (`--enable-gpl --enable-version3`, no `--enable-nonfree`) from the ffmpeg-static b6.1.1 release for each platform. The release's licence file ships with the app as `LICENSE.ffmpeg.txt` and is shown in Settings → Licences.

Source:

- FFmpeg: https://ffmpeg.org/download.html
- The ffmpeg-static release the programs come from: https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.1.1

## Chrome Headless Shell (recording and export browser)

Opsis doesn't include the recording browser: Settings → Engine downloads Chrome Headless Shell (Chromium, BSD-3-Clause, plus the licences of every library it includes) from Google's Chrome for Testing onto the user's computer, or uses a browser the user chooses. The complete licence notices of the pinned build ship with the app in `engine-licences/LICENSES.chromium.html`, saved at build time from the `chrome://credits` page of the full Chrome for Testing build of the exact same version. Source: https://chromium.googlesource.com/chromium/src · builds: https://googlechromelabs.github.io/chrome-for-testing/

The Mac cursor style draws the macOS cursor set of apple_cursor by ful1e5 (https://github.com/ful1e5/apple_cursor), commit fe044a4, licensed under the GNU General Public License version 3, the licence of Opsis itself (`LICENSE`). `bun run cursors:bundle <checkout>` copies the SVGs the CSS cursor keywords use, recoloured as its `macOS` theme does, with their hotspots.
